# micrograd → Agent Firewall (Experiment)

This is an experimental fork of micrograd exploring a simple idea:

> Can we treat signals (like gradients) as indicators of unsafe AI behavior?

## What I added
- A minimal "Agent Firewall" hook
- Detects abnormal gradient signals
- Prints alerts when thresholds are crossed

## Why this matters
As AI agents become autonomous, we need:
- real-time monitoring
- policy enforcement
- safety layers between decision and action

This repo is an early exploration of that idea.

## Direction
This evolves toward:
PrivateVault.ai → The Agent Firewall for AI systems
